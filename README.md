# DC Motor Direction Control Using H-Bridge

## Overview
This project demonstrates bidirectional DC motor control using an H-Bridge circuit built with NPN transistors.

The circuit was explored using Tinkercad Circuits to understand how transistor switching controls the direction of current flow and motor rotation.

## Objectives
- Understand the working principle of an H-Bridge.
- Learn the operation of NPN transistors.
- Explore bidirectional DC motor control.
- Understand electronic switching circuits.

## Components Used
- NPN transistors
- DC motor
- Push buttons
- 9V battery
- Connecting wires

## Working Principle
An H-Bridge is an electronic circuit used to control the direction of a DC motor.

By changing the switching combinations of the transistors, the direction of current through the motor can be reversed.

This allows the motor to rotate in both forward and reverse directions.
